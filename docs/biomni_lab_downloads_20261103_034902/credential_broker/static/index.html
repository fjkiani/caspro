CrisPRO Credential Broker

Paste tokens to open live connections. Secrets are held encrypted in memory only — never written to disk, never logged, never shown back.

How this works. Credentials live only in the running server's memory (encrypted) and vanish when it stops. Synapse and CAS are validated and then usable directly for analysis.
