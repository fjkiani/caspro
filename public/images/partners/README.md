# Partner Images Directory

This directory contains all partner-related images organized by category.

## Folder Structure

```
public/images/partners/
├── events/           # Event photos, conferences, meetings
├── logos/           # Partner organization logos
├── case-studies/    # Images for case study presentations
├── testimonials/    # Photos of testimonial authors
└── README.md        # This file
```

## Usage Guidelines

### Events (`/events/`)
- Conference photos
- Meeting snapshots
- Partnership announcement events
- Award ceremonies
- Product launches

**Naming Convention**: `YYYY-MM-DD-event-name-description.jpg`
Example: `2024-01-15-aacr-conference-partnership.jpg`

### Logos (`/logos/`)
- Official partner organization logos
- High-resolution versions for print
- Web-optimized versions
- Different formats (PNG, SVG, JPG)

**Naming Convention**: `partner-name-logo-format.ext`
Example: `aacr-logo-white.png`, `uc-berkeley-logo-color.svg`

### Case Studies (`/case-studies/`)
- Screenshots of platform usage
- Before/after comparisons
- Data visualizations
- Research results

**Naming Convention**: `partner-name-case-study-type.jpg`
Example: `aacr-brca1-variant-analysis.jpg`

### Testimonials (`/testimonials/`)
- Professional headshots
- Team photos
- Office environments
- Research lab photos

**Naming Convention**: `partner-name-person-title.jpg`
Example: `aacr-dr-sarah-chen-director.jpg`

## Image Specifications

### Recommended Formats
- **Web**: JPG (80% quality), WebP (preferred)
- **Print**: PNG, TIFF
- **Logos**: SVG (vector), PNG (raster)

### Size Guidelines
- **Web images**: Max 1920px width, optimized for web
- **Thumbnails**: 300x300px for previews
- **Logos**: Multiple sizes (16px, 32px, 64px, 128px, 256px)

### File Size Limits
- **Web images**: < 500KB
- **High-res images**: < 2MB
- **Logos**: < 100KB

## Adding New Images

1. Choose the appropriate folder based on image type
2. Follow the naming convention
3. Optimize the image for web use
4. Update this README if adding new categories
